# TJob: Мобильное приложение для оптимизации процессов найма

## О проекте
**TJob** — это мобильное приложение для Android, разработанное для структурирования и оптимизации процессов найма сотрудников в компаниях. Приложение позволяет снизить текучесть кадров и повысить производительность рекрутинга за счет автоматизации ключевых этапов подбора персонала.

### Ключевые возможности
- **Отслеживание прогресса найма** на всех этапах
- **Поиск кандидатов** по внутренней базе данных компании
- **Управление вакансиями** (создание, редактирование, отслеживание)
- **Координация собеседований** и согласование времени
- **Разграничение ролей** для рекрутеров, интервьюеров и руководителей команд

## Технический стек
- **Язык программирования**: Kotlin
- **Архитектура**: MVVM (Model-View-ViewModel)
- **UI фреймворк**: Jetpack Compose
- **Сетевые запросы**: Ktor Client
- **Минимальная версия Android**: API 21 (Android 5.0+)

## Архитектура проекта
Проект реализован с использованием многомодульной архитектуры:

### Уровни модулей:
1. **`:core`** — базовые компоненты (темы, утилиты, общие зависимости)
2. **`:data`** — работа с данными (сущности, репозитории, источники данных)
3. **`:feature`** — экраны и UI-компоненты (по одному модулю на фичу)

### Ключевые особенности архитектуры:
- **Однонаправленный поток данных**
- **Отсутствие циклических зависимостей**
- **Высокая тестируемость компонентов**
- **Быстрая сборка за счет параллельной компиляции модулей**

## Функциональные требования

### Для всех пользователей:
- 📋 Просмотр статуса интервью
- ⏰ Согласование времени с кандидатами
- 📝 Оставление фидбэка по собеседованиям

### Для рекрутеров:
- 🔍 Поиск кандидатов по фильтрам
- 🎯 Создание и редактирование вакансий
- 📤 Приглашение кандидатов на вакансии
- 🔄 Управление процессом найма (треками)
- 👥 Смена интервьюеров для собеседований

### Для руководителей команд:
- 👁️‍🗨️ Просмотр статуса треков кандидатов
- 📊 Мониторинг вакансий и кандидатов
- ✨ Отслеживание ключевых вакансий

### Для интервьюеров:
- 🎯 Включение/выключение режима собеседующего
- 👁️ Просмотр назначенных собеседований

### Шаги для запуска:

```bash
# 3. Сборка и запуск на эмуляторе или устройстве
```

## Основные экраны приложения

### 1. Главный экран
- Ближайшие интервью, требующие внимания
- Быстрый доступ к отслеживаемым вакансиям
- Поиск кандидатов и вакансий

### 2. Экран вакансии
- Информация о вакансии
- Кандидаты на отборе
- Подавшие заявку кандидаты
- Базовый трек вакансии

### 3. Экран кандидата
- Профиль кандидата
- История собеседований
- Активные треки и заявки

### 4. Экран собеседования
- Детали интервью
- Статус и этапы
- Фидбэк и результаты

## Преимущества выбранного стека
